Working Backwards

Define what done looks like and the evidence that would prove it, then walk back to now, so every step exists because the one after it needs it.

Best for a Project, a Goal · Amazon, early 2000s · takes an hour, then revisits

How to run it

  1. Write done as a state of the world, not an activity, dated in the future, as a stranger would report it. Name who would have to agree it is done.
  2. List the evidence that would prove it. Numbers where there are numbers. Something a person outside the work could point at.
  3. Write the questions a sceptic would ask. How much did it cost? What went wrong? Why hasn’t someone done this already? Answer each honestly, and notice which you can’t.
  4. Now walk back. What has to be true just before that ending? Write it as something that has become true, say how you would see it, and say what must already be true just before it.
  5. Keep walking until the chain touches today. Then say honestly where you actually are, which is rarely where the chain assumed.
  6. Name the first move, the one you could make this week from exactly here, and write down what the chain still assumes.

Where it falls down. It is only as good as the honesty of the ending.

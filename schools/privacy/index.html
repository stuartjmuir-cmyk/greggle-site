Privacy summary for schools

Greggle collects no student data. Here is how to check.

One page for a board, a principal or a privacy officer. Everything on it can be verified by a member of your own IT staff in ten minutes.

What Greggle is

A free web app in which a student names something they are working on, cuts it into steps, and uses structured thinking methods (5 Whys, Pre-mortem, Working Backwards and others) to break it down. It runs in the browser and installs as an app on Chromebooks, iPads and laptops without administrator involvement.

What it collects

Nothing. There are no accounts, so no names, emails or logins. There is no server, so nowhere for work to go. There are no analytics, no tracking and no third-party scripts, fonts or images. Student work stays in the browser on the device and in a file the student saves and moves themselves.

Why this is true rather than promised

The app is delivered with a Content-Security-Policy that forbids outbound network connections outright: the browser itself refuses to let the page fetch, post or send a beacon anywhere, including back to its own server. An automated test asserts that the app makes no request to another origin, and another asserts that the policy is present every time it is built. The app is a set of static files; there is no backend to be breached.

Check it yourself

  1. Turn off the wifi and keep working. Everything carries on. Software that needed to send data somewhere could not do that.
  2. Watch the Network tab in the browser's developer tools while a student uses it. After the page loads there are no outgoing requests.
  3. Read the Content-Security-Policy in the page source at www.greggle.app. It is a short instruction to the browser to refuse outbound connections.

What this means for your school

No data processing agreement, because there is no processing. No privacy impact assessment, because there is no personal information. No hosting conversation, because nothing is hosted. No accounts to provision, and none to remove at the end of the year.

In one sentence

Greggle never receives, stores or processes anything a student writes, and the software is built so that it cannot.
